# Metal Divergence Analysis

Gold-Silver pairs trading research project. Cointegration-based statistical arbitrage on GLD/SLV with walk-forward validation, OU-modeled spread dynamics, and regime stress testing.

See `PLAN.md` for the full research plan and phase-by-phase deliverables.
See `CLAUDE.md` for coding conventions.

## Setup

```bash
python -m venv .venv
source .venv/Scripts/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
